# Chess Coach

Play the Stockfish engine in the browser and get every move rated, with the better move shown.

One self-contained page. Built from `app.src.html` by `build.py`.

Third-party parts, each under its own licence:
- Stockfish.js 10 (GPL-3.0), https://github.com/nmrugg/stockfish.js
- chess.js 0.10.3 (BSD-2-Clause), https://github.com/jhlywa/chess.js
- Opening names from lichess-org/chess-openings (CC0)
- Piece images: cburnett set by Colin M.L. Burnett (GPL-2.0-or-later), via lichess-org/lila

This repository is released under GPL-3.0.
